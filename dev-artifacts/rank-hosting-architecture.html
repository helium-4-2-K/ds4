GLM 5.2 on 4x GX10: Tensor-Parallel Rank Hosting

Dedicated architecture view for the BCD artifacts. The key invariant is TP4/PP1: every rank hosts shards for every layer and runs each decode layer in lockstep. Rank 0 adds API and sampling duties; it is not a layer-stage owner.

What Is Sharded

  • Q is query-head sharded: 16 of 64 query heads per rank.
  • K is MLA-aware: shared kv_lora[512]/k_rope[64] semantics plus rank-owned k_b slices for the owned query heads.
  • Each rank owns shards for all GLM 5.2 layers, not a layer range.

What Is Replicated

  • Model metadata and launch configuration are logically shared across ranks.
  • Hidden state becomes replicated only after explicit TP collectives.
  • KV shape and cursor metadata are replicated; KV/MLA cache contents are rank-owned slices.

Token j Decode

  • Rank 0 receives the request and broadcasts the hidden input.
  • Ranks 0-3 compute local QKV/attention/FFN/logits shards in lockstep.
  • Collectives produce replicated hidden after attention and FFN; rank 0 gathers/top-k logits and samples token j.
